# MD5 校验工具 Pro

macOS 风格的 Windows 桌面 MD5 校验工具：拖入即算，结果自动写入 Excel。

![icon](icon.png)

## 功能

- **拖入即算**：文件（支持多选）直接拖进窗口自动计算；拖入文件夹自动递归扫描批量计算
- **选择文件 / 选择文件夹**：按钮入口，与拖拽等效
- **校验比对**：粘贴已知 MD5（32 位），算完自动显示 ✅一致 / ❌不一致
- **Excel 自动记录**：每算完一个文件立刻把「文件名 + MD5」等追加写入 `MD5校验记录.xlsx`（含大小、创建/修改时间、耗时、文件路径），持续累积；表格被 Excel/WPS 占用时自动另存新表
- **复制 / 导出 TXT**：一键复制全部结果，或另存 txt 报告
- **停止 / 清空**：中断计算、清空列表

## 界面

macOS 深色风格：无边框窗口 + 红绿灯按钮、毛玻璃卡片、实时进度条、逐文件耗时展示。

## 环境要求

- Windows 10 / 11
- Python 3.10+
- 依赖：`pywebview`、`openpyxl`

```bat
pip install pywebview openpyxl
```

## 运行

```bat
python MD5校验工具.py
```

或直接双击 `启动MD5校验工具.bat`（注意：bat 里的 Python 路径默认为 `D:\python\pythonw.exe`，请按自己机器修改）。

## 目录结构

```
MD5校验工具Pro/
├── MD5校验工具.py        # 主程序（MD5 计算、Excel 记录、窗口控制）
├── ui.html               # 界面（单文件 HTML/CSS/JS）
├── app.ico / icon.png    # 应用图标
├── 启动MD5校验工具.bat     # 双击启动脚本
└── 使用说明.md            # 中文使用手册
```

## 说明

- 同一次运行内重复拖入的文件会自动跳过
- 读取失败的文件（被独占占用等）会单独标红，不影响其他文件
- 缺少依赖时程序会弹窗提示，并在目录下生成「启动错误.log」
